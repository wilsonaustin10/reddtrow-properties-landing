# Landing Page Variations Build Plan v2.0
## Home Buyers - Google Ads Optimization

---

## Project Overview

**Objective:** Create keyword-matched landing page variations aligned with 5 strategic ad groups to maximize Google Ads Quality Score and lead form conversion rates.

**Source Data:** 67 high-intent keywords from 730 analyzed, organized into 5 ad groups by intent level.

**Budget Context:** $50/day ($1,500/month) — targeting 28-37 conversions/month at 15% CVR

**Priority:** Ad Groups 4 & 5 (Distressed + Ugly Houses) get 60% of budget due to lowest CPCs ($5-8) and highest conversion intent. Landing pages for these groups are TOP PRIORITY.

## Technical Implementation

### Lead Form Specification

```typescript
interface LeadFormData {
  // Required fields
  propertyAddress: string;    // With Google Places autocomplete
  fullName: string;
  phone: string;              // With input mask: (555) 555-5555
  email: string;

  // Optional qualifying fields
  propertyCondition?: 'excellent' | 'good' | 'fair' | 'poor' | 'very_poor';
  timeline?: 'asap' | '2_weeks' | '30_days' | '60_days' | 'flexible';
  situation?: 'foreclosure' | 'divorce' | 'relocation' | 'inherited' | 'repairs' | 'other';

  // Hidden tracking fields (auto-populated)
  utmSource?: string;
  utmMedium?: string;
  utmCampaign?: string;
  utmContent?: string;
  utmTerm?: string;
  gclid?: string;
  landingPage: string;        // Current page slug
  adGroup?: string;           // Mapped from landing page
}
```

### Tracking Setup

```javascript
// On successful form submission
window.dataLayer = window.dataLayer || [];
```
